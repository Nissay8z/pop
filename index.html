🤖 Modèles de Chat & Raisonnement

⭐ MEILLEUR POLYVALENT

Llama 3.2 / 3.3

Le modèle open source le plus polyvalent. Excellent en raisonnement, code, et français.

🖥 RAM : 4-16 Go selon la taille
📦 Tailles : 3B · 8B · 70B
ollama run llama3.2:3b Ollama
🧠 MEILLEUR RAISONNEMENT

DeepSeek R1

Raisonnement avancé "chain of thought". Excellent pour les problèmes complexes et les maths.

🖥 RAM : 8-32 Go
📦 Tailles : 7B · 14B · 32B
ollama run deepseek-r1:7b Ollama
🇫🇷 MEILLEUR EN FRANÇAIS

Mistral / Mixtral

Modèle français d'excellence. Très bon en français natif, rapide et efficace.

🖥 RAM : 4-24 Go
📦 Tailles : 7B · 8x7B MoE
ollama run mistral:7b Ollama
💨 ULTRA RAPIDE

Qwen 2.5

Très rapide avec un énorme contexte (128k tokens). Parfait pour analyser de longs documents.

🖥 RAM : 4-16 Go
📦 Tailles : 3B · 7B · 14B · 32B
ollama run qwen2.5:7b Ollama

💻 Modèles Spécialisés Code

⭐ MEILLEUR CODE

Qwen2.5 Coder

Le meilleur modèle open source pour le code. Supporte 40+ langages, autocomplete, debugging.

🖥 RAM : 6 Go minimum
📦 Tailles : 3B · 7B · 14B · 32B
ollama run qwen2.5-coder:7b Code

Architecture MoE, très efficace. Excellent en Python, JavaScript, C++, SQL.

📦 Tailles : 16B (actif 2.4B)
ollama run deepseek-coder-v2:16b Code
🦙 META CODE

Code Llama

Le modèle code de Meta. Bon en génération, complétion, et débogage de code Python/JS/Java.

🖥 RAM : 4-16 Go
📦 Tailles : 7B · 13B · 34B
ollama run codellama:7b Code
⚡ MINI RAPIDE

StarCoder2

Spécialisé pour 600+ langages de programmation. Très léger et rapide, parfait sur CPU.

🖥 RAM : 3 Go minimum
📦 Tailles : 3B · 7B · 15B
ollama run starcoder2:3b Code

🎨 Génération d'Images

⭐ MEILLEUR IMAGE

Flux.1

Le modèle image open source le plus impressionnant. Qualité proche de MidJourney. SDXL architecture.

🖥 GPU : 8 Go VRAM minimum (12+ idéal)
🔧 Via : ComfyUI ou A1111
↗ HuggingFace ComfyUI
🎯 POLYVALENT

SDXL (Stable Diffusion XL)

Standard de l'industrie open source. Énorme communauté, des milliers de LoRA & checkpoints.

🖥 GPU : 6 Go VRAM minimum
🔧 Via : A1111 ou ComfyUI
↗ HuggingFace A1111
💨 ULTRA RAPIDE

SD Turbo / SDXL Turbo

Génération quasi-instantanée (1-4 steps). Parfait pour tester des prompts rapidement.

🖥 GPU : 4 Go VRAM
⚡ Vitesse : ~1 seconde
↗ HuggingFace
🖥 CPU OK

SD 1.5

L'original. Léger, fonctionne même sur CPU (lentement). Base parfaite pour apprendre.

🖥 GPU : 4 Go VRAM ou CPU
📦 Taille : ~2 Go
↗ HuggingFace

1

Installer Ollama (chat & code)

Le moteur universel pour tous les LLM. S'installe en 30 secondes.

curl -fsSL https://ollama.com/install.sh | sh # Windows : télécharge sur ollama.com # Puis active CORS : OLLAMA_ORIGINS=* ollama serve
2

Télécharger un modèle

Via Ollama (le plus simple) ou depuis HuggingFace (.gguf pour LM Studio)

ollama pull llama3.2:3b # 4 Go RAM (CPU ok) ollama pull qwen2.5-coder:7b # 8 Go RAM (code) ollama pull deepseek-r1:7b # 8 Go RAM (raisonnement) # HuggingFace direct : ollama run hf.co/bartowski/Llama-3.2-3B-Instruct-GGUF
3

Installer Automatic1111 (images)

L'interface la plus simple pour Stable Diffusion. Lance avec --api pour connecter NEXUS.

git clone https://github.com/AUTOMATIC1111/stable-diffusion-webui cd stable-diffusion-webui # Linux/Mac : ./webui.sh --api --cors-allow-origins=* # Windows : webui-user.bat # puis ajouter --api dans COMMANDLINE_ARGS
4

Installer SearXNG (recherche web privée)

Moteur de recherche local qui agrège DuckDuckGo, Google, Bing sans tracker.

docker run -d -p 8080:8080 \ -e "SEARXNG_SETTINGS_SEARCH_FORMATS=[html,json]" \ searxng/searxng # Puis active le format JSON dans : # http://localhost:8080/preferences
5

Ouvrir NEXUS

Double-clique sur index.html dans Chrome ou Firefox. Configure le modèle dans ⚙ Settings. C'est tout !

# Optionnel : lancer un mini serveur pour éviter les CORS python -m http.server 3000 # Puis ouvrir http://localhost:3000/index.html
